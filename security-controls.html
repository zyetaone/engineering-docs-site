The evidence column is meant to be run, not read. If a command cannot produce a result, the control is not in place, whatever the settings page suggests.

Evidence collection

For a review, a release, or an audit, collect one file:

{
  echo "# Control evidence $(date -u +%FT%TZ)"
  echo
  echo '## Drift'
  enterprise/governance/verify.sh --org <org> --repo <org>/archify
  echo
  echo '## Rulesets'
  gh api orgs/<org>/rulesets --jq '.[] | {name, target, enforcement}'
  echo
  echo '## Environments'
  gh api repos/<org>/archify/environments --jq '.environments[] | {name, protection_rules}'
  echo
  echo '## Scanning'
  gh api repos/<org>/archify --jq .security_and_analysis
  echo
  echo '## Latest release provenance'
  gh release view --json tagName,assets --jq '{tagName, assets: [.assets[].name]}'
} > "evidence/controls-$(date -u +%Y%m%d).md"

Store it with the release record. A control with no evidence line is open, even if this table says otherwise.
